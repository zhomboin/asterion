# Asterion

在自己的 Linux 或 WSL 终端执行 `bash start.sh`，打开本机面板，输入 SSH 地址或别名即可连接服务器，查看状态并在终端执行命令。使用预构建运行包可以直接启动。节点复用已有的 SSH 服务和账号。
