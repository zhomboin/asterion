# Asterion

Asterion 只在本机运行。在自己的 Linux 或 WSL 电脑上解压运行包，执行 `bash start.sh`，然后在面板输入 SSH 地址或别名，即可查看服务器状态并执行命令。远端复用已有的 SSH 服务和账号，所有连接由本机发起。
