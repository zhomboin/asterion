# Asterion

Asterion 是面向个人和小型基础设施的自托管监控与运维平台。中心从 Linux VPS 和 WSL Ubuntu Agent 接收心跳与指标，提供节点查询、服务资产、告警和历史趋势。受控操作、Linux 账号变更与交互终端由部署者按需授权。
