# Asterion

Asterion 面板在本机运行。在 Linux 或 WSL 电脑上解压运行包，执行 `bash start.sh`。打开「节点 → 接入服务器」，填写 SSH 地址和认证信息。首次连接在面板核对主机指纹，接入后即可查看状态并执行命令。远端复用已有的 SSH 服务和账号。在节点详情打开「监控部署」即可安装离线采集器。
