# 产品需求

[Windows 原生工作区](windows-desktop.md)和 Linux 面板均可通过 SSH 管理节点。下表列出两种客户端提供的业务功能。具体入口、平台差异及验证范围见[桌面功能对照](desktop-parity.md)。

Asterion 面板在用户自己的 Linux 或 WSL 电脑上运行。打开本机面板，填写 SSH 地址或别名即可监控服务器、管理容器并执行命令。在节点的「监控部署」中安装[服务器端采集器](collector.md)后，节点可以离线保存主机指标，面板重新连通后自动补回历史。

| 场景 | 用户可见结果 |
| --- | --- |
| 接入与总览 | 填写节点别名、主机、端口和认证信息，或选择命名连接。首次连接在面板核对 SSH 指纹，已知主机密钥冲突时阻止连接。总览显示节点状态、最近采样和利用率。 |
| 主机与服务监控 | 查看主机指标、短期历史、长期趋势、进程详情、Docker 状态及日志、systemd 服务和持续监控。 |
| 服务资产 | 登记服务位置和归属，关联同节点的发现记录，区分人工填写与观测信息。 |
| 运维操作 | 在对应面板安装软件、编辑并应用配置、管理容器、启停服务、发送进程信号、运行预定义命令。操作需确认并记录结果。 |
| 文件编辑 | 查看 Nginx 主配置及引用文件，编辑后校验并请求重载。也可按绝对路径读取和保存远程文本文件。 |
| 账号与终端 | 读取账号信息，管理指定普通账号的用户组与 SSH 公钥。启用后可打开绑定到面板会话的主机或容器终端。 |
| 告警 | 节点离线、指标越限和已监控服务异常可触发告警；恢复后显示恢复记录。 |

面板及管理接口需要身份验证。本机程序验证 SSH 主机密钥，保存任务审计和执行结果。操作权限取决于目标 SSH 账号及本机配置的资源范围。WSL 的监控范围是所选 Linux 发行版。节点无法访问时仍能查看本机已保存的记录。
