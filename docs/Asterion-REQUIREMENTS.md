# 产品需求

Asterion 面向管理 Linux、WSL 和容器服务的管理员。一个中心通过已有 SSH 访问各节点，节点接入后能直接查看运行状态，并在同一面板完成确认、执行和结果核对。

| 场景 | 用户可见结果 |
| --- | --- |
| 接入与总览 | 选择 SSH 配置、编辑名称和标签、关联宿主机。总览显示节点状态、最近采样和利用率。 |
| 主机与服务监控 | 查看主机指标、短期历史、长期趋势、进程详情、Docker 状态及日志、systemd 服务和持续监控。 |
| 服务资产 | 登记服务位置和归属，关联同节点的发现记录，区分人工填写与观测信息。 |
| 运维操作 | 在对应面板安装软件、编辑并应用配置、管理容器、启停服务、发送进程信号、运行预定义命令。操作需确认并记录结果。 |
| 账号与终端 | 读取账号信息，管理指定普通账号的用户组与 SSH 公钥。启用后可打开绑定到面板会话的主机或容器终端。 |
| 告警 | 节点离线、指标越限和已监控服务异常可触发告警；恢复后显示恢复记录。 |

面板及管理接口需要身份验证。中心验证 SSH 主机密钥，保存任务审计和执行结果。操作权限取决于目标 SSH 账号及中心配置的资源范围。WSL 的监控范围是所选 Linux 发行版。节点无法访问时仍能查看中心已保存的记录。
