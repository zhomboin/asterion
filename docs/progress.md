# 项目进度

| 功能 | 当前状态 |
| --- | --- |
| 本机面板 | Linux 或 WSL 解压后运行，面板默认监听 `127.0.0.1:17110`，可通过 `ASTERION_LOCAL_PORT` 指定其他本机端口。 |
| 节点接入 | 填写主机、端口和认证信息后，在面板核对首次连接的 SSH 指纹。已信任的节点可直接连接。 |
| 监控与资产 | 提供指标、趋势、告警、进程、Docker、systemd 及按节点关联的服务资产。 |
| 运维 | 软件安装、配置编辑、容器、账号、公钥、预定义命令及交互终端通过 SSH 执行。实际权限取决于 SSH 登录账号。 |
| 发布 | CI 构建本机运行包，在 Ubuntu 22.04 和 24.04 验收解压、首次登录、停止和重启。 |
