# 项目进度

| 功能 | 当前状态 |
| --- | --- |
| [Windows 桌面版](windows-desktop.md) | 原生窗口接入 Linux 节点，核对主机指纹后通过密码或私钥登录，查看短期指标趋势并打开交互终端。 |
| 本机面板 | Linux 或 WSL 解压后运行，面板默认监听 `127.0.0.1:17110`，可通过 `ASTERION_LOCAL_PORT` 指定其他本机端口。 |
| 节点接入 | 填写主机、端口和认证信息后，在面板核对首次连接的 SSH 指纹。已信任的节点可直接连接。 |
| 监控与资产 | 提供指标、趋势、告警、进程、Docker、systemd 及按节点关联的服务资产。 |
| [离线采集](collector.md) | 节点页支持通过 SSH 部署、更新和配置 Rust 采集器，systemd 管理服务，按期限与容量清理，恢复 SSH 后按原采样时间补传。[推送前验证](development.md#推送前验证采集器部署)覆盖 SSH 读取权限与补传。 |
| 运维 | 软件安装、配置编辑、容器、账号、公钥、预定义命令及交互终端通过 SSH 执行。实际权限取决于 SSH 登录账号。 |
| [文件编辑](managed-operations.md) | 可从 Nginx 实例的配置清单选择文件，保存、检查并请求重载，也可按绝对路径打开和保存普通文本文件。 |
| 发布 | CI 构建本机运行包，在 Ubuntu 22.04 和 24.04 验收解压、首次登录、停止和重启。 |
