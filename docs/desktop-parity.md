# Linux 面板与 Windows 桌面版功能对照

下表按 Linux 面板里的实际操作列出 Windows 原生入口。「工作区」指 Windows 应用右上角的「管理工作区」。连接和远程操作使用所选 SSH 账号，两端共用节点指标、资产、告警、任务确认及审计的 Rust 业务逻辑。

| Linux 面板操作 | Windows 原生入口及行为 |
| --- | --- |
| 登录、设置、退出 | 解锁工作区后，在「设置」查看本机账号、采样间隔、保留天数和终端开关。「锁定」结束工作区连接。 |
| 节点接入与管理 | 「SSH 连接」支持密码、指定私钥、OpenSSH 别名和命名连接。可单独核对主机指纹。节点详情支持编辑资料、断开、更改地址及移除。改址保留节点 ID、关联资产和历史，冲突地址或未完成任务会阻止更改。 |
| 节点总览 | 搜索、按状态筛选及翻页，查看在线率、最近采样和活动告警。节点详情可进入该节点的资产及任务。 |
| 主机指标与趋势 | 「主机指标」提供一小时和一天采样、文件系统及网卡详情。「长期趋势」提供七天和三十天的利用率、吞吐及采样覆盖情况，缺采区间断开显示。 |
| 进程及关注清单 | 搜索进程、查看详情、按策略发送信号。「关注清单」按准确名称列出当前匹配的进程，打开详情时复核 PID 与启动时间。 |
| Docker 及关注清单 | 查看引擎、容器、资源统计和不同长度的日志。关注状态按引擎及容器 ID 匹配，区分引擎变化、未找到和清单截断。 |
| systemd 持续监控 | 发现服务、查看详情，授权服务可启停或重启。「持续监控」可启用、停用、显示已停用条目及查看状态历史。 |
| 服务资产 | 按节点、管理方式及标签筛选。可选择归属节点，编辑、人工核实、关联或解除同节点发现记录，打开仓库及返回所属节点。 |
| 告警事件与规则 | 选择节点和事件状态。从指标告警进入节点，从服务告警进入对应服务的历史，在「告警规则」为指定节点增删改规则。 |
| 命令、软件、配置与容器 | 「运维操作」提供预定义命令、软件安装、配置保存与重载，以及受管容器的创建、重建和启停。重建表单带回当前方案的重启策略、端口与挂载。 |
| 文本及 Nginx 文件 | 按绝对路径打开文本或从 Nginx 清单选文件。支持重新读取、复制、确认保存及冲突后的草稿恢复。混用换行符时在保存前提示。 |
| 系统账号与公钥 | 搜索账号和 UID，查看组、Shell、主目录，按读取权限查看公钥指纹。在策略允许的普通账号上可创建账号、编辑附加组和增删公钥。 |
| 任务与审计 | 按节点查询任务，查看确认期限、执行结果、错误、取消时间和审计。允许取消的任务可请求取消，受保护的变更需再输入工作区口令。 |
| 主机及容器终端 | 打开 SSH PTY，支持改变窗口尺寸、功能键、滚动、中文输入和多行粘贴确认。主机终端校验非 root 身份，容器终端校验策略与目标容器。 |
| 远端采集器 | 「采集器部署」展示架构、安装及运行状态，可沿用配置或调整间隔、天数和容量。部署后新建 SSH 会话验证采样，恢复连接后补传历史。 |

## 运行方式与验证范围

- Linux 面板使用本机 Web 会话和 OpenSSH。Windows 使用 iced 窗口、工作区口令和本机 SQLite。选择保存 SSH 密码时使用当前 Windows 用户的 DPAPI，换电脑或 Windows 账号后需重新输入密码。
- Windows 的「解锁工作区后自动连接」按节点启用。应用关闭或工作区锁定期间，工作区采样、服务检查和告警评估暂停。已部署的远端采集器可继续保留主机指标。
- Windows 本机 SSH 配置可使用私钥、SSH Agent、跳板与标准输入输出代理。主机信任校验使用普通主机公钥和已知主机文件。仅提供主机证书的服务器、仅支持 Unix 文件描述符传递的代理需要相应的普通公钥或标准输入输出连接配置。
- 桌面回归用例覆盖节点改址与任务冲突、凭据隔离、资产与告警归属、关注对象、容器重建参数、账号权限、文件版本及图表缺采。SSH 联调验证连接、真实采样、文件读写、旧版本拒绝和任务执行。采集器安装、容器重建及生产服务启停的结果取决于目标节点的权限和运行环境。
