# 专用操作面板

## 文件编辑

1. 在「节点」打开在线的 SSH 节点，选择「文件编辑」。通过面板接入的节点默认启用此功能，远端需有 Python 3.9 或以上版本。
2. 编辑 Nginx 时，在「当前配置引用的文件」中选择主配置或其中任一引用文件。面板读取宿主机 Nginx 主进程的启动参数，用 `nginx -T` 列出磁盘上的配置树。它反映下次重载要读取的内容。符号链接会显示实际目标，保存时保留链接。
3. 修改后点击「保存并重载 Nginx」，核对路径并输入本机面板口令确认。面板备份原文、写入修改，再按同一实例的参数执行 `nginx -t`。校验通过后向该主进程发送重载信号；校验或发送失败时尝试恢复原文。在编辑器下方查看结果，校验失败时可继续修改草稿。重载信号的最终处理结果可在 Nginx 错误日志中核对。
4. 编辑其他文件时，在「手动打开文件」中填写已有文本文件的绝对路径，点击「打开」。修改后点「保存文件」并确认。此入口只写文件。支持最大 64 KiB 的 UTF-8 普通文件。文件已被其他人修改时，先复制要保留的草稿，再点「重新读取」核对。

SSH 账号需能读取文件，保存时还需有文件及所在目录的写权限。文件有多个硬链接时无法原子保存。Nginx 操作需要能检查完整配置，并有权向主进程发送信号。找不到可识别的宿主机实例、发现多个实例或配置检查失败时，仍可手动打开文件。保存备份在 SSH 账号的私有目录 `~/.asterion-operations/`，任务记录保存路径、摘要和结果。

## 按策略启用的面板

在[本机模式](local.md)下，直接连接的非 root 节点可从「终端」输入命令。要启用下表中的操作，在本机数据目录的 `profiles.json` 增加条目，名称使用节点详情显示的完整 SSH 连接标识，如 `ssh://app`，条目中填写 `policy` 对象。保存后原节点自动加载。对于已配置策略或通过具名配置接入的节点，在 `policy` 中增加 `"file_editor": true` 即可允许按自由路径编辑文件。

专用面板需要目标机提供 Python 3.9 或以上版本。预定义命令默认提供只读的 `uptime`。只为实际需要的操作填写策略，样例中的目标和镜像摘要须替换为已核实的值。[配置样例](../deploy/ssh.example.json)

| 面板 | 本机配置 | 执行条件 |
| --- | --- | --- |
| 软件安装 | `managed.packages` 中的软件包名 | 目标为 Debian/Ubuntu，SSH 身份可运行包管理器 |
| 服务配置 | `managed.configs` 中的路径、可编辑字段、校验器和服务名 | 可原子写入文件并重载服务，保存前复核原内容，重载失败时尝试回滚 |
| 容器管理 | `managed.containers` 的 Engine ID、镜像摘要、端口和挂载，或已有容器 ID | 目标存在 Docker CLI、可用镜像及相应 Engine 权限 |
| 服务与进程操作 | `systemd_units`、`docker_targets`、`process` | 操作前检查 Unit、Engine 与容器，或 PID 与启动时钟 |
| 预定义命令 | `commands` 中的程序绝对路径、参数规则和超时 | 固定参数或经校验的参数按独立参数传入程序 |
| Linux 账号和公钥 | `accounts.usernames` 和 `accounts.groups` | 写操作限指定普通账号，创建账号和更改用户组需要目标账号已有管理权限 |

在节点详情中选择操作，检查目标及参数并确认。涉及账号、强制终止或受管资源变更时需复核面板口令。任务页显示退出状态、输出和执行人。每次操作使用 SSH 登录账号已有的权限。配置备份与容器绑定按需写入 SSH 用户私有的 `~/.asterion-operations`，公钥变更备份在目标用户的 SSH 目录。

本机面板默认启用交互终端，启动时可设置 `ASTERION_TERMINAL_ENABLED=0` 关闭。主机终端使用目标普通 SSH 账号，容器终端还要求对应容器配置启用 `terminal` 并通过绑定和隔离检查。终端空闲两分钟或达到十五分钟会关闭，注销面板会话也会关闭所属终端。

软件安装、配置保存和容器变更在目标机上按 SSH 用户串行执行。连接中断后，已开始的变更会在时限内继续；重新提交前先刷新目标状态。普通命令随连接关闭而停止。
