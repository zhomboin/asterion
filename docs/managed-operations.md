# 专用操作面板

在[本机模式](local.md)下，直接连接的非 root 节点可从「终端」输入命令。如果要为该节点启用专用操作，在本机数据目录的 `profiles.json` 增加条目，名称使用节点详情显示的完整 SSH 连接标识，如 `ssh://app`。条目中只写下文的 `policy` 对象。保存后原节点自动加载并继续使用本机 SSH 凭据。

在 SSH 连接中增加可选的 `policy` 对象。完整字段见[发布样例](../deploy/ssh.example.json)。只填写需要的操作范围，样例中的目标和镜像摘要须替换为实际已核实的值。未配置策略的连接可以采集监控和执行只读的 `uptime` 命令。

| 面板 | 中心配置 | 执行条件 |
| --- | --- | --- |
| 软件安装 | `managed.packages` 中的软件包名 | 目标为 Debian/Ubuntu，SSH 身份可运行包管理器 |
| 服务配置 | `managed.configs` 中的路径、可编辑字段、校验器和服务名 | 可原子写入文件并重载服务，保存前复核原内容，重载失败时尝试回滚 |
| 容器管理 | `managed.containers` 的 Engine ID、镜像摘要、端口和挂载，或已有容器 ID | 目标存在 Docker CLI、可用镜像及相应 Engine 权限 |
| 服务与进程操作 | `systemd_units`、`docker_targets`、`process` | 操作前检查 Unit、Engine 与容器，或 PID 与启动时钟 |
| 预定义命令 | `commands` 中的程序绝对路径、参数规则和超时 | 固定参数或经校验的参数按独立参数传入程序 |
| Linux 账号和公钥 | `accounts.usernames` 和 `accounts.groups` | 写操作限指定普通账号，创建账号和更改用户组需要目标账号已有管理权限 |

在节点详情中选择操作，检查目标及参数并确认。涉及账号、强制终止或受管资源变更时需复核面板口令。任务页显示退出状态、输出和执行人。中心不自动提权。配置备份与容器绑定按需写入 SSH 用户私有的 `~/.asterion-operations`，公钥变更备份在目标用户的 SSH 目录。

交互终端在中心设置 `ASTERION_TERMINAL_ENABLED=1` 后生效，启用时将整个管理入口限制在可信网络。主机终端使用目标普通 SSH 账号，容器终端还要求对应容器配置启用 `terminal` 并通过绑定和隔离检查。终端空闲两分钟或达到十五分钟会关闭，退出面板也会关闭所属终端。

软件安装、配置保存和容器变更在目标机上按 SSH 用户串行执行。连接中断后，已开始的变更会在时限内继续；重新提交前先刷新目标状态。普通命令随连接关闭而停止。
