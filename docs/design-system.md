# Asterion 前端设计规范

本文说明 Asterion 管理面板的视觉风格与组件用法。新增页面沿用现有组件和样式。新增共用样式时，同步更新[设计变量](../web/src/styles/tokens.css)和本文。

## 1. 风格定位：单色柔光玻璃（Monochrome Soft Glass）

| 原则 | 说明 |
| --- | --- |
| 单色为主 | 基础配色使用灰阶，黑色突出当前导航、主按钮、强调卡片和代码面。 |
| 柔光玻璃 | 浅灰渐变画布上叠加半透明白色卡片，配合细白描边与大范围柔和投影。 |
| 圆润 | 卡片使用大圆角，按钮、导航项、筛选控件、标签全部为胶囊形，图标按钮为正圆。 |
| 克制的颜色 | 绿、红和琥珀分别用于在线、离线或失败、待处理。红色也用于错误提示和危险操作。 |
| 大标题、小标签 | 页面标题使用大号粗体与紧凑字距；说明文字、字段名使用小号灰色。 |

## 2. 文件结构

| 文件 | 职责 |
| --- | --- |
| [tokens.css](../web/src/styles/tokens.css) | 共用颜色、圆角、阴影、间距、字号、控件尺寸与动效。 |
| [base.css](../web/src/styles/base.css) | 重置、画布背景、标题排版、通用文字工具类。 |
| [components.css](../web/src/styles/components.css) | 可复用组件样式（按钮、表单、卡片、分段切换、状态、表格、对话框等）。 |
| [layout.css](../web/src/styles/layout.css) | 应用布局：侧边栏、顶栏、页面标题、登录舞台、响应式断点。 |
| [pages.css](../web/src/styles/pages.css) | 页面级组合（总览网格、节点列表、趋势图、终端）。 |
| [ui.tsx](../web/src/ui.tsx) | 页面共用的 React 组件。 |

样式按变量、基础样式、组件、布局、页面的顺序导入。见[前端入口](../web/src/main.tsx)。

## 3. 设计令牌

### 3.1 颜色

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--canvas` | `#e4e4e6` | 页面底色（叠加径向高光渐变） |
| `--frame` | 白 46% | 登录卡片 |
| `--surface` | 白 82% | 卡片、侧边栏、表格容器 |
| `--surface-solid` | `#fff` | 按钮、输入框、列表项、顶栏胶囊 |
| `--surface-sunken` | 黑 4% | 分段切换底槽、卡片内信息格、标签 |
| `--inverse` | `#161617` | 强调：当前导航、主按钮、强调卡片、代码面、终端 |
| `--ink` / `--ink-2` / `--muted` | `#161617` / `#434347` / `#636368` | 主文字 / 次文字 / 说明文字 |
| `--line` / `--line-strong` | 黑 8% / 16% | 分隔线 / 悬停描边 |
| `--online` / `--offline` / `--pending` | `#2f8a5f` / `#c4473c` / `#b0851f` | 状态色 |

### 3.2 圆角、阴影、尺寸

| 类别 | 令牌 |
| --- | --- |
| 圆角 | `--radius-sm` 12px（输入框）· `--radius-md` 16px（列表项、信息格）· `--radius-lg` 24px（卡片）· `--radius-xl` 32px（对话框）· `--radius-pill`（按钮、导航、标签） |
| 阴影 | `--shadow-xs`（按钮、胶囊）· `--shadow-sm`（卡片）· `--shadow-md`（强调卡片、终端）· `--shadow-lg`（对话框） |
| 控件高度 | `--control-sm` 2rem · `--control-md` 2.5rem（默认）· `--control-lg` 3rem（导航、CTA、顶栏胶囊） |
| 间距 | 4px 基线：`--space-1` 至 `--space-6` 及 `--space-8`；卡片内边距 `--space-5`，网格间距 `--space-4` |

### 3.3 字体

- 无衬线：`Inter` → 系统 UI 字体 → `PingFang SC` / `Microsoft YaHei` / `Noto Sans CJK SC`。
- 等宽：`JetBrains Mono` → `Consolas`，用于 ID、命令、日志、终端（类名 `.technical`）。
- 字号：页面标题 `--text-display`（字重 600，字距 -0.045em）；大数字 `--text-figure`；正文 `--text-md`；字段名与表头 `--text-xs`。
- 大数字、指标和表格时间采用等宽数字，便于对齐。

## 4. 应用外壳

侧边栏与工作区直接排布在页面背景上，外层仅提供网格和页边距。节点详情在页签内显示分页后的纳管清单，搜索入口归入「添加监控」对话框。

- 侧边栏导航项：图标 + 文字，胶囊形；当前页 `aria-current="page"` 显示为黑底白字。
- 用户卡片固定在侧边栏底部：头像、用户名、角色、退出图标按钮。
- 顶栏展示日期、最近一次会话检查反映的中心连接状态，以及用于打开告警的黑色圆形按钮。
- 登录、加载和连接失败使用居中的 `.stage` + `.stage-card` 玻璃卡片。

### 响应式断点

| 宽度 | 行为 |
| --- | --- |
| > 64rem | 侧边栏 15rem，显示图标与文字 |
| > 40rem 且 ≤ 64rem | 侧边栏收窄为 4.75rem，显示图标，导航链接保留可读名称。 |
| ≤ 40rem | 导航移到顶部，图标和文字可横向滚动。 |

## 5. 组件

优先使用[共享组件](../web/src/ui.tsx)。

| 组件 | 用法 |
| --- | --- |
| PageHeader | 每个管理页面提供一个标题，可附返回链接、范围和右侧操作。 |
| Card | 用白色玻璃卡片分组内容。需要强调时可用黑色卡片，每屏最多一张。 |
| Tabs | 分段切换使用浅灰底槽和白色选中项。嵌在卡片中时使用小尺寸。 |
| CallToAction | 用带圆形图标的黑色胶囊突出主操作，每页最多一个。 |
| IconButton | 正圆图标按钮须提供可读名称，同时用于读屏和提示。 |
| Icon | 线性图标使用 24 单位画布、1.6 线宽和圆角端点。 |
| Avatar | 显示名称开头的字符，有三个尺寸。 |
| Meter | 显示 0 至 100 的进度并提供说明，颜色继承所在元素的文字色。 |
| NodeStatus | 用同色浅底、圆点和文字显示节点状态。 |
| DataTable | 表格提供名称和可聚焦的滚动区域，行悬停时提亮。 |
| Pagination | 右侧显示上一页、页码和下一页。 |
| Problem | 错误提示使用淡红底和红色圆点，右侧提供重试按钮。 |
| Brand | 黑色球形标记与 Asterion 字标链接到总览。 |

### 5.1 按钮层级

| 类名 | 外观 | 场景 |
| --- | --- | --- |
| 默认 `button` | 白色胶囊、细描边 | 次要操作：筛选、刷新、编辑、取消 |
| `.primary` | 黑色胶囊 | 表单提交、确认 |
| `.primary.cta` | 黑色胶囊 + 白圆图标 | 页面主操作（通过 `CallToAction`） |
| `.quiet` | 透明，悬停浅灰 | 行内操作、关闭 |
| `.danger` / `.danger.primary` | 红字 / 红底 | 删除、吊销、停止；破坏性确认必须用 `.danger.primary` |

### 5.2 仅用类名的模式

| 类名 | 说明 |
| --- | --- |
| `.detail-panel` | 与 `Card` 同外观，供表单 / 详情面板直接使用 |
| `.detail-facts` | 信息格网格（默认 4 列，`.asset-facts` 为 2 列）；卡片内自动变为浅灰底格 |
| `.filter-bar` | 白色玻璃条中的筛选表单，字段自动换行，按钮与输入框底部对齐 |
| `.fields` / `.form-grid` | 竖向表单 / 两列表单 |
| `.status`、`.operation-state[data-state]` | 状态胶囊 |
| `.tags` | 浅灰胶囊标签 |
| `.empty` | 虚线圆角空状态 |
| `.output`、`.argument-list`、`.terminal-screen` | 黑色代码面 |
| `.text-link` | 黑字 + 淡下划线，悬停加深 |
| `.figure` | 大号数字，`<small>` 用于单位 |

## 6. 图表

- 线条使用灰阶区分：CPU `--gray-900`、内存 `--gray-500`、磁盘 `--gray-400` 虚线。
- 网格线为 `--line` 虚线；坐标轴文字 9px `--muted`。
- 图例使用圆点，不使用色块。

## 7. 编写规则

1. 页面和组件使用现有设计变量。局部光效按所在组件或布局维护。
2. 管理页面用 PageHeader 显示标题，用 Card 分组内容，用 Tabs 切换视图，用 CallToAction 突出主操作。
3. 黑色强调卡片、代码面与终端用于聚焦内容。同一视口内最多一张强调卡片。
4. 状态同时用颜色和文字表达。
5. 所有图标按钮必须有可读标签；可交互元素保留 `:focus-visible` 黑色外框。
6. 将新增共享组件封装在 [ui.tsx](../web/src/ui.tsx)，在 [components.css](../web/src/styles/components.css) 添加样式，并补充本文的组件表。
