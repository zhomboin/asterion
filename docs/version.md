# 版本记录

## Windows 桌面版

- 原生管理工作区支持多节点、资产、告警、受管运维和采集器部署。与 Linux 面板共用业务校验和任务审计，便携包附带两种 Linux 架构的采集器。

- 新增 Rust 与 iced 原生客户端，支持 SSH 节点连接、指纹确认、本机历史趋势和可调整大小的交互终端。

## 本机运行包

- 采集器部署提供针对 SSH 只读权限、权限拒绝和断线补传的推送前预检。

- 节点详情提供「监控部署」，支持通过现有 SSH 连接安装和更新采集器、设置保留策略及验证首批采样。发布包包含 x86_64 与 ARM64 采集器。

- 增加可选的 Rust 服务器采集器、systemd 服务和 SSH 断点补传。远端缓存默认 7 天、256 MiB，面板按采样时间独立保留原始数据和长期趋势。

- 节点详情新增「文件编辑」，支持 Nginx 配置发现、编辑、语法检查、重载和失败回滚，也可按绝对路径编辑 UTF-8 文本文件。

- 接入页收紧布局，主机与端口并排，收起可选设置，移除节点标签。首次 SSH 连接可在面板核对指纹，密钥变更时阻止连接。
- 接入和管理节点时可填写主机、端口、用户名和别名，选择密码、指定私钥或本机 OpenSSH 配置。
- 本机面板默认监听 `127.0.0.1:17110`，可通过环境变量 `ASTERION_LOCAL_PORT` 指定其他端口。
- 本机启动是唯一支持的运行方式。服务器直接部署、安装向导和公网 HTTPS 发布包已退役。CI 直接构建并验收本机运行包。
- 提供可解压运行的 Linux / WSL 面板，支持直接输入 SSH 地址或别名、复用本机 SSH 凭据和打开交互终端。
- 本机直连可用标准 Linux 命令采集基础指标。

## SSH 接入

- 节点监控、运维和交互终端改由中心通过 SSH 发起，发布包只包含中心服务。
- 保留现有专用面板，资源范围集中配置；已有节点可补绑 SSH 连接并沿用历史记录。

## 0.1.0

- 中心部署向导可按目标启用服务配置编辑与重启、Docker 容器启停及受管容器方案，复用当前发布并自动配置所需权限。

- 中心一键部署支持可选的本机 Docker 只读采集。已有中心可直接补配读取服务和 Agent 权限，并以 Agent 身份验证容器清单。

- Ubuntu 22.04 和 24.04 支持 root 或有 sudo 权限的普通用户用一条命令从源码构建并部署中心。续装会复用已有发布包、运维账号和服务状态，并自动检查 HTTPS、证书续期和本机 Agent 指标。

- 面板支持动态公网 IP，登录接口按来源限速。新签公网证书由 Certbot 通过 HTTP 验证域名、定时续期并重载 Nginx；部署、节点接入及恢复指南区分公网证书与内部 CA，并提供迁移后的续期验收命令。

- 分开记录开发电脑启动和服务器独立部署。部署指南涵盖域名代理、中心自监控和个人运维账号，实例参数采用占位符。

- 接入服务器、节点管理及 Agent 部署使用独立页面。支持通过 SSH 首次安装或在同一节点重新部署 Agent。配置页用终端提示符标记命令，实时输出和错误按执行顺序连续显示，部署完成后检查新的心跳。

- 增加节点软件安装、受管配置文件编辑及重载、Docker 容器服务创建与重建、挂载选择和容器终端；systemd 清单提供直接启停与结果核验。

- 提供 HTTPS 面板、单管理员会话、Agent 注册认证、稳定节点身份和心跳。总览展示全局在线统计及节点最新 CPU、内存和磁盘采样，支持手动关联宿主机。
- 提供主机指标、按需进程查询、Docker 与 systemd 发现、服务资产检索和来源管理。进程详情显示可确认的 systemd Unit 或 Docker 容器归属，主机指标独立于实时查询采样。Docker Engine 身份按观测节点保存，覆盖空 Engine。
- 提供白名单任务、确认与口令复核、发起会话取消、增量输出和审计。
- 提供 Linux 账号和 SSH 公钥、可选终端、阈值告警和长期趋势。注销时关闭当前登录会话创建的终端。
- 支持选定 systemd 服务的持续监控、状态变化历史和停机恢复告警。
- 校验 Agent 重连和终端会话的并发边界，处理无响应体的任务确认与取消，收紧进程组清理、公钥备份和恢复后的凭证处理。
- 统一登录页与管理面板的布局、响应式导航、共享组件和样式变量。
- 增加接入服务器入口及 Agent 配置，进程、容器和 systemd 默认显示已纳管对象，发现和监控清单分页展示，实时查询校验纳管对象的名称或容器身份。
