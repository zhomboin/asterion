# ADR-007 运维执行与外部集成

面板管理员先准备任务，再按节点、目标、动作和参数确认。确认凭证绑定发起任务的管理员会话，2 分钟有效且只用一次。进程 KILL 和 Linux 账号变更还需重新验证面板管理员口令。任务与审计持久化并按节点限并发。预定义命令执行中的输出快照受限，中心保留最新记录及最终结果。取消执行中的任务时中心等待 Agent 报告实际结果，重启后将未完成的任务标记为中断。

Agent 使用本机策略限制具体 Unit、完整容器身份、进程信号和预定义命令。Agent 重新核对目标、参数、时限及重放状态。预定义命令只能来自管理员提供的目录，使用校验过的绝对路径和参数数组。Linux 账号与 Docker 变更可以经独立本机辅助程序执行，辅助程序再次验证策略。只在经过配置的普通账号和组范围内修改 Linux 用户或公钥。

终端另有独立授权、管理员口令和会话。中心只允许在回环或私有地址上开启该功能。两端明确启用后，独立终端服务以不同于 Agent 的普通 Linux 账户运行。Agent 校验 Unix Socket 对端 UID。shell 和子进程不能创建新会话或改换进程组。空闲两分钟或总时长十五分钟时会话结束。会话输入输出不进入审计记录。

LocalOpsGateway 是可选集成。中心和 Agent 不依赖它。本仓库的 Docker 和 Linux 账号辅助服务使用各自明确的本机权限边界。接入外部执行服务应单独核实授权、幂等、审计和超时语义，并由管理员按资源配置允许范围。
