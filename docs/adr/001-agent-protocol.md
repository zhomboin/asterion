# ADR-001 Agent 连接协议

Agent 主动通过 TLS WebSocket 连接中心的 `/api/v1/agent/connect`，面板与 Agent 共用一个 HTTPS 端口。中心先检查设备或注册凭证，再接收第一条 `hello` 并回复带节点 ID 的 `welcome`。首次注册的节点 ID 可为空。Agent 每 5 秒发送心跳。中心使用到达时间更新心跳，20 秒未见有效心跳时节点离线。

协议兼容范围为 1 至 2。中心接受协议 1 的握手和心跳，涉及采样和远程读写的面板请求返回升级提示。升级时先更新中心，再逐台更新 Agent。协议 2 的连接另有以下消息。

| 方向 | 消息 | 用途 |
| --- | --- | --- |
| 中心到 Agent | `configure` | 下发采样间隔 |
| Agent 到中心 | `metrics` | 上报当次主机指标 |
| 中心到 Agent | `task` | 携带任务 ID、操作类型、参数和到期时间 |
| Agent 到中心 | `task_progress` | 携带任务 ID 和受限输出快照 |
| Agent 到中心 | `task_reply` | 携带对应任务 ID 和受限的结果或错误 |
| 中心到 Agent | `cancel_task` | 请求取消指定任务 |

消息包含协议版本、节点 ID、连接内序号、Unix 时间戳及类型和负载。中心核对节点范围、最新连接代次、序号和消息大小，单帧上限 256 KiB。每个节点的队列有容量上限。任务断开、超时或取消时结束中心等待。Agent 在连接中断后退避重连，已确认的变更由中心持久化，执行不确定的变更不会自动重发。
