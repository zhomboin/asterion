# 宿主机和节点身份

节点以面板生成的 128 位 ID 标识。可在「管理节点」中修改直连节点的别名、地址和认证方式。变更地址、用户名或端口时，选择密码认证需重新输入密码。使用 OpenSSH 别名时也可以更新本机 SSH 配置。命名连接通过同名配置条目维护。指标、资产和任务以节点 ID 关联。

宿主机是可选的逻辑实体。相同类型和宿主机标识的节点归到同一宿主机。WSL 节点显示发行版自身的连通与运行状态。

Docker 容器在当前节点通过 Engine ID 和完整容器 ID 识别。进程身份包括 PID 和内核启动时钟；systemd 服务使用具体 Unit 名。发现记录与资产须属于同一节点。
