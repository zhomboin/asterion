# ADR-002 TLS 和设备凭证

浏览器和远端 Agent 通过同一面板域名访问 Nginx。Nginx 使用 Let's Encrypt 证书；中心主机上的 Certbot 通过 DNS-01 验证域名，定时续期成功后先检查 Nginx 配置，再平滑重载。公网证书的私钥和 DNS 令牌只留在中心主机，不向节点分发。

中心进程在回环地址使用内部 CA 签发的 PEM 证书提供 HTTPS 和 WSS。Nginx 和监控中心自身的 Agent 都校验这张内部证书；它不由 Certbot 续签。远端 Agent 校验公网域名、证书链和有效期，默认使用系统信任根。TLS 证书续期与节点设备凭证换发是两个独立操作。

管理员登录使用 Argon2id 哈希。会话 Cookie 使用 `Secure`、`HttpOnly` 和 `SameSite=Strict`。中心仅保存随机会话凭证的 SHA-256 摘要，会话最长有效 12 小时，注销即时撤销当前会话。

每个节点的注册凭证单独生成，10 分钟内可消费一次。Agent 在第一次连接前生成并持久化独立的随机设备凭证。中心在身份和版本校验成功后，原子消费注册凭证并保存设备凭证的 SHA-256 摘要。确认帧传输失败时，可用相同的设备凭证重连。持续连接仅以该节点的设备凭证鉴权。

重新签发同一节点的注册凭证时，旧设备凭证和旧注册凭证被作废，节点 ID 保持稳定。也可仅吊销凭证并保留节点。操作步骤见[服务器部署与恢复](../deployment.md)和[公网证书签发与续期](../public-tls.md)。
