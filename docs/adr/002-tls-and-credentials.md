# ADR-002 TLS 和设备凭证

中心使用 PEM 证书链和私钥提供 HTTPS 和 WSS。Agent 检查中心地址、证书链和有效期，支持在系统信任根之外提供私有 CA。浏览器通过同一 HTTPS 服务访问面板。

管理员登录使用 Argon2id 哈希。会话 Cookie 使用 `Secure`、`HttpOnly` 和 `SameSite=Strict`。中心仅保存随机会话凭证的 SHA-256 摘要，会话最长有效 12 小时，注销即时撤销当前会话。

每个节点的注册凭证单独生成，10 分钟内可消费一次。Agent 在第一次连接前生成并持久化独立的随机设备凭证。中心在身份和版本校验成功后，原子消费注册凭证并保存设备凭证的 SHA-256 摘要。确认帧传输失败时，可用相同的设备凭证重连。持续连接仅以该节点的设备凭证鉴权。

重新签发同一节点的注册凭证时，旧设备凭证和旧注册凭证被作废，节点 ID 保持稳定。也可仅吊销凭证并保留节点。部署、恢复与证书更换步骤见[远程部署](../deployment.md)。
