# ADR-003 SQLite 存储与采样

本机面板使用一个 SQLite 文件，由 SQLx 在启动时应用迁移，启用外键和 WAL。退出程序后，备份整个数据目录即可保留一致的数据库和本机连接配置。节点、任务和资产用稳定 ID 引用。

按本机接收时间索引原始指标，节点系统的采样时间随数据保留。默认每 15 秒采样、保留 7 天，可分别配置采样间隔和保留天数。历史接口提供最近 1 小时或 24 小时的分桶采样。空桶和暂无速率的接口保持缺测。超量采样和超大结果有上限。

长期趋势在原始采样写入时更新 5 分钟汇总。提供 7 天、30 天的视图，汇总默认保留 90 天，可单独配置。汇总包含采样数及有效 CPU、内存、磁盘和网络速率的平均值。磁盘利用率取该次采样中占用率最高的挂载点。原始采样与长期汇总独立清理。短期和长期数据都按节点隔离；资产、运维与告警不随指标清理。
